# Events Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Bengaluru tech-events tracker. It reads Luma, GDG and Eventbrite through means each permits, lists events by date with a deterministic relevance verdict, lets a user save, mark going, download an `.ics` and note who they met, and feeds the Overview day plan, the company drawer and (through a read-only contract) Outreach.

**Architecture:**
- Pure rules in `domain/`:
  - `event_time` (IST helpers)
  - `event_facts` (the parser output type)
  - `ical` (parse and build)
  - `event_relevance` (the verdict with reasons)
  - `event_identity` (dedupe and company candidates)
  - `event_urls` (strict pasted-link patterns)
- Thin I/O in `services/events/`:
  - one parser and fetcher per source, each tested on recorded fixtures
  - `store` (upsert, dedupe, link, assess)
  - `refresh.run_step` (bounded, never raises, behind `SourceHealthService`)
  - `read`, `user`, `met` (the Outreach contract)
- A thin router `api/routers/events.py`. Copilot cards for the day plan.
- On the frontend, an `/events` page, an `EventMap` reusing the extracted MapLibre setup, a company-drawer block, and `buildActions` ranking.

**Tech Stack:** FastAPI, async SQLAlchemy, Alembic, httpx, stdlib `json`/`re`/`gzip`, BeautifulSoup (already a dependency) for locating script tags, Next.js 14, `maplibre-gl` 6.11.2 (already installed). No new Python or npm dependency.

**Spec:** `docs/superpowers/specs/2026-10-15-events-design.md` (with `2026-10-14-outreach-suite-roadmap.md` and `2026-10-14-company-map-design.md`)

## Global Constraints

- **Zero cost.** No LLM, Tavily or Nominatim call anywhere in this feature. The Eventbrite token is optional (`EVENTBRITE_TOKEN`); without it, the source is skipped.
- **Luma:** only `https://api.lu.ma/ics/get?entity=discover|calendar&id=<id>` with an id matching `^(discplace|cal)-[A-Za-z0-9]{6,40}$`. Each feed at most once per 11 h (cache key `tr:events:luma:<id>:read`), 1 req/s, ≤ 26 feeds a run. A pasted Luma link is never fetched.
- **GDG:** only `https://gdg.community.dev/<chapter-slug>/` and `/events/details/<slug>/`. Never a path under `/api/`, `/gql/`, `/accounts/`, `/u/`, `/newsletter/`, `/triggers/` or `/health/`. 2.0 s between requests, ≤ 30 a run, each event page at most once per 3 days unless its start changed. `addressCountry` is never trusted.
- **Eventbrite:** only `https://www.eventbriteapi.com/v3/...` with `Authorization: Bearer <token>`. 1 req/s, ≤ 60 calls a run. Never request `www.eventbrite.*` pages.
- **Every fetch:** User-Agent `TalentRadar/1.0 (+https://github.com/AjitShetti/talentRadar)`, 15 s timeout, 1 MB body cap (stream and stop), `follow_redirects=False` for GDG and Luma.
- **Breaker keys:** `events:luma`, `events:gdg`, `events:eventbrite` via `services.source_health.SourceHealthService`.
- **Times** are stored `timestamptz`. Everything a person reads uses `domain.event_time.IST = timezone(timedelta(hours=5, minutes=30), "IST")`. A null `ends_at` means start + 2 h.
- **Never write `now()` into `starts_at`.** An event without a source start is not stored.
- **Cancelled** only from an explicit source signal: iCal `STATUS:CANCELLED`, JSON-LD `EventCancelled`, Eventbrite `status == "canceled"`. A missing listing is never a cancellation.
- **An event never creates a company.** Links only to `companies.is_tech IS TRUE`, through `services.company_map.store.find_existing`.
- **People met are private:** every query is filtered by `user_id`. They are never enriched, never looked up and never in a public payload.
- **Every scheduled step never raises.** It returns `{"step": …, "error": …}`.
- **Migration:** revision `018_events`, `down_revision = "016_company_is_tech"`. It creates only the four new tables and is IF NOT EXISTS-safe.
- **Code quality:** mypy strict, ruff (isort first-party list), full annotations.
- **Frontend:**
  - DESIGN.md: hairline rows, One Lamp Rule, FlapText on live numbers.
  - Keyboard operable, works at 375 px.
  - `frontend/lib/api.ts` is the only API client.

## Review Focus

1. **The IST day boundary.** An event at 00:30 IST on Friday is "tomorrow" on Thursday at 23:50 IST, and "today" at 00:10 IST, even though both moments are the same UTC date as its start. Test: `test_today_window_uses_ist_midnight` in Task 1.
2. **The same meetup on Luma and Eventbrite** with titles "Swift Bengaluru × Okta" and "Swift Bengaluru Meetup at Okta" 15 minutes apart. It is one listed row with an "Also on" link. Two different meetups at the same venue an hour apart stay two rows. Tests: `test_cross_source_duplicate_is_hidden_and_linked` and `test_same_venue_different_event_stays_two` in Task 8.
3. **A hostile pasted link**: `https://eventbrite.com.evil.io/e/x-123`, `https://user@gdg.community.dev/events/details/x/`, `https://gdg.community.dev/api/event/1`, `javascript:alert(1)`, a 5,000-char URL. None is fetched; each gets `needs_details`. Test: `test_hostile_links_are_not_matched` in Task 3, and `test_import_never_requests_unmatched_url` in Task 13.
4. **A user reading or editing another user's people-met rows** or private manual event. That is a 404, never data. Tests: `test_people_are_private_to_their_user` and `test_manual_event_invisible_to_others` in Task 13.
5. **A feed that loses an event before it happens.** The row stays listed and is not cancelled; an explicit `STATUS:CANCELLED` cancels it. Test: `test_absent_from_feed_is_not_cancelled` in Task 8.

### Task 1: Time, facts and iCal (pure)

**Files:**
- Create: `domain/event_time.py`, `domain/event_facts.py`, `domain/ical.py`
- Test: `tests/test_event_time_ical.py`

**Interfaces:**
- Produces:
  - `domain.event_time`:
    - `IST: timezone`, `DEFAULT_DURATION = timedelta(hours=2)`
    - `ist_date(moment: datetime) -> date`
    - `effective_end(starts_at: datetime, ends_at: datetime | None) -> datetime`
    - `Window = Literal["today", "week", "weekend", "month"]`
    - `window(name: Window, now: datetime) -> tuple[datetime, datetime]`, giving UTC-aware bounds:
      - `today`: from IST midnight to the next IST midnight
      - `week`: from now to +7 d
      - `weekend`: from the coming Saturday 00:00 IST to Monday 00:00 IST, or from now if it is already the weekend
      - `month`: from now to +30 d
    - `is_today(starts_at: datetime, ends_at: datetime | None, now: datetime) -> bool`: the IST date of the start is today, and the event has not ended.
    - `when_label(starts_at: datetime, ends_at: datetime | None) -> str`, e.g. `"Thu 15 Oct · 18:30–20:00 IST"`. When the end falls on another day: `"Sat 24 Oct 09:30 – Sun 25 Oct 17:00 IST"`.
  - `domain.event_facts`:
    - `@dataclass(frozen=True) EventFacts(source: str, external_id: str, url: str, title: str, starts_at: datetime, ends_at: datetime | None = None, snippet: str | None = None, venue_name: str | None = None, address: str | None = None, locality: str | None = None, lat: float | None = None, lng: float | None = None, area: str | None = None, address_withheld: bool = False, is_online: bool = False, is_free: bool | None = None, organiser_name: str | None = None, organiser_url: str | None = None, hosts: tuple[str, ...] = (), is_cancelled: bool = False, timezone: str | None = None, taxonomy: Mapping[str, str] = field(default_factory=dict))`
    - `@dataclass(frozen=True) SourceScope(key: str, india: bool, trusted_tech: bool)`
    - `flatten(text: str | None, limit: int) -> str | None`: strip tags, unescape entities, collapse whitespace, bound at a word with "…". It never returns an empty string.
  - `domain.ical`:
    - `@dataclass(frozen=True) IcalEvent(uid: str, summary: str, description: str | None, location: str | None, dtstart: datetime, dtend: datetime | None, geo: tuple[float, float] | None, status: str | None, organizer_cn: str | None)`
    - `MAX_ICAL_BYTES = 1_048_576`
    - `parse_ical(data: bytes) -> list[IcalEvent]`: unfolds lines, unescapes `\n \, \; \\`, and reads `DTSTART` as `…Z`, `TZID=Asia/Kolkata:…`, floating (taken as IST) or `VALUE=DATE` (00:00 IST). It skips a VEVENT with no UID or DTSTART. Oversize or malformed input gives `[]`, never an exception.
    - `build_ics(*, uid: str, title: str, starts_at: datetime, ends_at: datetime, location: str | None, url: str, description: str | None, cancelled: bool, stamp: datetime) -> str`: CRLF line endings, folded at 75 octets, `PRODID:-//TalentRadar//Events//EN`, times in UTC `Z`.

  - `window("today", now)[0] == datetime(2026,10,14,18,30,tzinfo=UTC)` for `now = 2026-10-15T10:00Z`.

  - `when_label(2026-10-15T13:00Z, 2026-10-15T14:30Z) == "Thu 15 Oct · 18:30–20:00 IST"`.
  - `flatten("<p>Hi &amp; bye</p>\n\n x", 600) == "Hi & bye x"`. `flatten("   ", 10) is None`. A 700-char input ends with "…" and has length ≤ 600.

    - `parse_ical(b"x" * (MAX_ICAL_BYTES + 1)) == []`, and `parse_ical(b"\xff\xfe garbage") == []`.
